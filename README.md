# UTS-WEB-NAMA

Portofolio interaktif untuk UTS Pemrograman Web, Prodi Sistem Informasi, Universitas Nusantara PGRI Kediri.

**Live:** https://wirayudharyan-png.github.io/UTS-WEB-RYAN-S.A.W/

## Fitur
- HTML5 semantik (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`) dengan meta tag lengkap
- Bootstrap 5.3 untuk layout responsif (desktop, tablet, mobile) + `css/style.css` kustom
- Dark mode (tersimpan di `localStorage`)
- Filter dan pencarian proyek
- Kalkulator estimasi biaya proyek
- Validasi formulir kontak

## Struktur
```
UTS-WEB-NAMA/
├── index.html
├── css/style.css
├── js/script.js
├── img/
└── README.md
```

## Menjalankan
Buka `index.html` di browser, atau gunakan GitHub Pages (Settings → Pages → Branch `main` / root).
